Machine learning

Success criteria: Understand the basics of machine learning and its applications.

Machine learning is a part of artificial intelligence that helps computers learn from information and make predictions. It can do things like sort pictures, look at data, and predict price changes. It can also find patterns and get better over time. Machine learning is used in a lot of things people use every day without even knowing it.

Algorithms have to be tested and changed to make sure they work correctly. Some algorithms use many layers to do harder tasks. This is called deep learning. It uses neural networks that work a bit like the human brain. These networks help computers learn from examples and improve with more information.

How machine learning learns

There are three main ways a model learns from information. Each works differently and has its own uses.

Supervised learning
Learns from labeled data: information that already has the right answers, like spam filters or stock price predictions. A common real-world example is credit card fraud detection. The model is trained on past transactions labeled “fraudulent” or “legitimate,” learns the patterns, and can then flag suspicious activity in real time.
Unsupervised learning
Finds patterns in unlabeled data. It uses information without labels and tries to find patterns on its own. Examples include grouping customers and finding unusual activity.
Reinforcement learning
Learns by trying things and getting feedback. Examples include video games, robots and self-driving cars. Over time, it learns which choices work best.

Problems with machine learning

Good information is needed
One big problem is that machine learning needs good information to work correctly, and getting it can take a lot of time and money. If the information is poor, the model might give wrong answers. Imbalanced data, overfitting and underfitting can also make a model work worse.
Some models are hard to understand
People might not know why the computer made a certain choice. There are also privacy, security and bias concerns, because models can sometimes give unfair answers or share private information. Models also need updating when things change.
Biased data, overfitting and data leakage
If the information a model uses is unfair or missing important details, it can make wrong choices. Overfitting is when a model memorizes its training data instead of learning patterns, so it struggles with new information. Data leakage is when a model sees information during training that it shouldn't have, making results look better than they really are.

Question 1 of 2

Which of these is NOT a common problem with machine learning models?

Data quality, hard-to-interpret models and biased data are all real problems with the models themselves. Researchers' motivation isn't a property of a model.

Question 2 of 2

What does supervised learning mean?

Supervised learning trains on labeled data: examples that already have the correct answer attached. Learning from feedback is reinforcement learning, and unlabeled data is unsupervised learning.
